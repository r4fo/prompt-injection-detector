# Raw Data

The project was built from three raw E2A benchmark archives:

- `prompt-injection.zip`
- `phishing.zip`
- `notinject.zip`

These archives are the inputs expected by `scripts/clean_data.py`.

The raw source data keeps its original attribution and license requirements.
See the repository-level `DATA_SOURCES.md` before redistributing any source archive.

For the final course submission, place the three original ZIP files in this
directory if redistribution is permitted and GitHub file-size limits allow it.
